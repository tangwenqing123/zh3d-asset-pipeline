# 提示词工程层 — 三风格族/词法铁律/安全词/变体组

## 三风格族基准卡（直接套用）

### 青铜雕塑族（神兽/神祇/人物雕塑）
```
写实神兽雕塑风格，博物馆收藏级，青铜釉色质感（青绿底色+鎏金{部位}纹理点缀），单只/单尊全身，正面对镜头居中构图，纯浅灰白背景无任何杂物，柔和摄影棚灯光，超高清细节。
```
个体句=姿态+持物+表情，例：`一只写实青铜釉色老虎雕塑，盘踞姿势，昂首正视前方，虎斑纹理清晰。`

### 写实器物族（场景件/民俗器物/现代物件）
```
一{量词}中式{物件}模型，{主体结构}，{材质质感}，底部平整，单体完整，纯白背景，无杂物无文字，高清3D资产。
```
结构词是硬通货（拱形桥洞/攒尖顶/三足双耳/镂空窗格），氛围词是废词。

### Q版黏土族（疗愈摆件/萌系）
```
一{量词}Q版黏土{物件}摆件，圆润{姿态}，{配色}，{表情}，哑光黏土质感，底部平整，单体完整，纯白背景，无杂物无文字，高清3D资产。
```

## 词法铁律（四条）

1. **重要词前置**：编码器对长句衰减，主体材质放最前
2. **词组化禁整句**：用名词短语堆叠，不写文学化长句
3. **结构词硬通货**：形状/部件/材质词有效；情绪/氛围/故事词无效
4. **白底居中思维**：提示词里的构图词服务图生3D的输入标准（纯白底/居中/全身/无文字）

## 3D安全词（碎件重灾区防治）

| 危险件 | 安全词写法 |
|---|---|
| 龙须/胡须/流苏 | "短而不飘""短流苏成绺" |
| 龙角/鹿角/枝杈 | "短粗圆润""贴头" |
| 鬃毛/长发 | "成绺贴伏""如雕刻" |
| 羽毛/翎羽 | "层叠贴伏""短翘不尖细" |
| 尾羽/裙摆飘带 | "上翘不尖细""垂坠贴体" |

原则：宁可牺牲飘逸感，不冒碎件风险（细长飘件在图生3D里断裂成刺的概率极高）。

## 变体组方法论（评测基准弹药）

同一母件做**同物异写**对照，四个维度：

1. **材质变体**：母件结构不变，材质词替换（红漆鎏金→紫檀绢面→玉石→三彩釉）
2. **配色变体**：色彩系统替换（青绿→影青→白底灰纹）
3. **跨风格族**：同一母题跨族（十二生肖"青铜雕塑↔Q版黏土"完整对=风格可控性证据）
4. **场景态变体**：同一场景换状态（荷花池夏景→秋色残荷；凉亭→积雪版）

价值：50组变体=中文3D提示词的"语法规律表"——哪个词改变什么，实物对照说话。

## 图生3D路线 vs 文生3D直出

| | 文生3D直出 | 豆包图→图生3D |
|---|---|---|
| 适用 | 器物/场景/摆件 | 角色/神兽（一致性要求高） |
| 成本 | 1额度 | 豆包免费+1额度 |
| 输入图四自检 | 无 | 纯白底/居中/全身/无文字 |
| 数据集链 | 三链（词→模→渲） | 四链（词→图→模→渲，更完整） |

主角级资产走图生3D（定妆图当锚），道具级走文生直出（省人工）。
